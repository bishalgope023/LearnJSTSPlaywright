# JavaScript Learning Exercises

This repository contains small, hands-on exercises for learning JavaScript and related development tools.

## JavaScript keywords and identifiers

[`02_chapter_JS_Keywords_Identifiers/09_IQ.js`](./02_chapter_JS_Keywords_Identifiers/09_IQ.js) demonstrates valid and invalid JavaScript identifier forms and common naming conventions.

The examples cover:

- Identifier starts and allowed characters, including letters, `_`, `$`, digits after the first character, and Unicode characters
- Case sensitivity
- Common naming styles: `camelCase`, `PascalCase`, `snake_case`, and `SCREAMING_SNAKE_CASE`
- Invalid identifier examples, kept in comments so the file remains executable

Run the example with Node.js from the repository root:

```powershell
node .\02_chapter_JS_Keywords_Identifiers\09_IQ.js
```

The file consists of declarations, so it does not print output when run.
